# Module 8 — Build Automation & CI/CD with Jenkins

This module covers build automation and continuous integration with Jenkins, from
installing Jenkins on a cloud server to creating pipelines, shared libraries,
webhook triggers, and dynamic version increments.

## Projects

| Folder | Project |
| --- | --- |
| `01-install-jenkins-on-digitalocean` | Install Jenkins on DigitalOcean |
| `02-ci-pipeline-with-jenkinsfile` | Create a CI pipeline with a Jenkinsfile |
| `03-jenkins-shared-library` | Reuse pipeline logic with a Jenkins shared library |
| `04-webhook-trigger-ci-pipeline` | Trigger a CI pipeline with a webhook |
| `05-dynamic-version-increment` | Increment application versions dynamically |
